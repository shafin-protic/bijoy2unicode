BanglaBridge: Smart Bijoy ↔ Unicode Bangla Converter
A lightning-fast, high-accuracy web application for bidirectional conversion between Bijoy (ANSI) and Unicode Bangla text. Designed for zero data loss, it features smart token-level script auto-detection to seamlessly handle mixed paragraphs containing Bijoy, Unicode, and English without corrupting URLs, emails, or English terminology.

Key Features
Smart Auto-Detection: Intelligently classifies mixed text input into Bijoy, Unicode, or English segments.

Flawless Reordering Engine: Advanced state-machine handling for pre-base vowels (ি, ে, ৈ), Reph (র্), Phalas, and complex consonant conjuncts.

Synchronized Highlighting: Real-time word-by-word visual linking between the input editor and output window.

Interactive Editing & Suggestions: Directly edit converted text with double-click contextual spelling suggestions and alternative orthography.

Modern OLED-Ready UI: Fully responsive dual-pane editor with instant Dark/Light mode switching.
